# Agent instructions

**UI or UX work:** read `docs/ui-rules.md` first, then `DESIGN.md`. They are binding, not suggestions. The short version, which applies to every UI change, is in `.agent/rules/ui-design.md`.

**Tests:** `npm test` (Node's built-in runner) must pass before you finish, including the translation test.

**Lint:** `npx eslint <files you touched>`.

**Git:** don't commit or push unless the user asks.
